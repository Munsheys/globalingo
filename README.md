# 🌍 GlobaLingo - Daily Language Snack

> Master one word, every day, from every corner of the world.

GlobaLingo is a gamified language learning experience that blends the daily habit of Wordle with the active pedagogy of Duolingo. It focuses on cultural immersion by teaching high-impact, untranslatable words from around the globe through voice interaction, character calligraphy, and memory puzzles.

---

## ✨ Features

- **🗺️ Global Word Discovery**: Select a country or go random to discover a unique daily word with its definition and etymology.
- **🎙️ Echo Check (Voice Feedback)**: Practice your pronunciation with real-time feedback using the Web Speech API. Includes a confidence gauge to track your accuracy.
- **✍️ Stroke Master (Calligraphy)**: A character-tracing mini-game that allows you to manually draw scripts (like Japanese Kanji or Arabic) directly on a digital canvas.
- **🧩 Definition Duel**: Reinforce your memory with rapid-fire definition matching games.
- **🔥 Daily Streaks**: Build your "Atlas Streak" by returning every day to conquer new linguistic territories.
- **🌿 Nomadic Minimalist Design**: A premium, dark-mode glassmorphic UI designed for an immersive and calming learning environment.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3 (Vanilla), JavaScript (ES6+)
- **Voice Engine**: Web Speech API (`SpeechRecognition` & `SpeechSynthesis`)
- **Canvas API**: For the manual character tracing system
- **Storage**: LocalStorage for streak persistence
- **Icons**: FontAwesome 6

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome or Edge is recommended for optimal Web Speech API support).
- Microphone access for voice exercises.

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/Munsheys/globalingo.git
   ```
2. Open `index.html` in your browser.

### Usage
1. Pick a region or start with a random word.
2. Listen to the pronunciation and practice speaking it back to the AI.
3. Trace the characters on the calligraphy canvas to build muscle memory.
4. Complete the definition quiz to finish your daily loop and grow your streak.
